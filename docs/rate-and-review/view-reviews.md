### View Reviews
#### Customer
| Use Case Name | Message |
| ------------ | ----- |    
| Summary: | The customer views ratings and reviews left by other customers who have ordered from that vendor. |
| Actors: | Customer |
| Preconditions: | The customer must be authenticated. |
| Postconditions: | The customer is able to read and view ratings left by other customers.
| Basic Flow | **Actor Action** |
|            | 1. Customer navigates to a vendor profile. |
|            | 2. Customer scrolls down the page to the Reviews section. |
|            | 3. Customer clicks the "See all reviews" option. |               
|            | **System Action** | 
|            | 3.1 The system loads in the review page, detailing the specific distribution of ratings and reviews left by other customers.|
|           | |
