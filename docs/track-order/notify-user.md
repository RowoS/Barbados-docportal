### Notify Users

| Use Case Name | Notify Users |
| ------------ | ----- |    
| Summary: | The system notifies the user of changes to the order. |
| Actors: | Vendor, Customer |
| Preconditions: | Any changes were applied to the order made by the customer. |
| Postconditions: | The specific changes are sent as notifications to the users.
| Basic Flow | **Actor Action** |
|            | 1. User performs a change with regards to an order. |             
|            | **System Action** | 
|            | 1.1 The system notifies both the customer and the vendor of the specific changes.|
