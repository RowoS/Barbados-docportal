### Search by Barangay

| Use Case Name | Search Store using Barangay |
| ------------ | ----- |    
| Summary: | The system displays a list of stores based on the location chosen by the customer. |
| Actors: | Customer |
| Preconditions: | The customer must be authenticated. |
| Postconditions: | The customer is able to scroll through the stores filtered through the search.
| Basic Flow | **Actor Action** |
|            | 1. Customer toggles the "Barangay" option located at the top-right of the map in the homepage. |
|            | 2. Customer selects a barangay from the provided options. |            
|            | **System Action** | 
|            | 3.1 The system provides the list of stores that have addresses matching the option chosen.|
|           | |
