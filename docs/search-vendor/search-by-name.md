### Search by Name

| Use Case Name | Search Store by Name |
| ------------ | ----- |    
| Summary: | The system displays a list of stores based on the search bar input from the customers. |
| Actors: | Customer |
| Preconditions: | The customer must be authenticated. |
| Postconditions: | The customer is able to scroll through the stores filtered through the search.
| Basic Flow | **Actor Action** |
|            | 1. Customer toggles the "Name" option located at the top-right side of the map in the homepage. |
|            | 2. Customer inputs desired keyword into the displayed search bar. |
|            | 3. Customer clicks "Enter". |               
|            | **System Action** | 
|            | 3.1 The system loads in all stores that match the input provided by the user.|
|           | |
